输入原文

把你的正文粘贴到下面的方框里，会自动按换行分段（每一行算一段）。也可以直接在方框里改字。

预览效果

这里模拟 AO3 默认阅读样式。选中文字后点右侧按钮即可改格式，效果立即显示在这里。

先在左边粘贴文字，点击"载入到预览区"，或者直接在这里开始写。

格式选项

加粗、斜体、引用、字号：先在中间预览区选中一段文字，再点按钮。行间距、段间距不用选中，直接调整下面的数字，全文立即生效。首行缩进比较特殊：不选中直接点 = 全文生效，选中某段再点 = 只对这一段单独开关。

基础格式（AO3 原生支持）

字号（需要配套 Work Skin）

改变选中文字的大小，生成 class="fs-large / fs-normal / fs-small"。

行间距（全文生效，无需选中）

直接设置整篇文字的行距倍数，拖动或输入数字即可，立即在预览区生效，下载时自动写进 Work Skin。

倍

段间距（全文生效，无需选中）

直接设置整篇段落之间的间距（单位 em），拖动或输入数字即可，立即在预览区生效，下载时自动写进 Work Skin。

em

首行缩进（需要配套 Work Skin）

「载入到预览区」时默认不缩进，避免和你自己手动打的缩进重复。不选中任何文字直接点这个按钮 = 对全文段落统一开关；先选中某一段再点 = 只单独开关这一段。
